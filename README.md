An entry for make.fun's "The Long Roast: Lawmakers and the File They Cannot Convert" bounty. The program writes a single satirical sentence — one line roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt`. Set `OUTPUT_DIR` to write elsewhere, e.g. `OUTPUT_DIR=/tmp/out python3 main.py`.
